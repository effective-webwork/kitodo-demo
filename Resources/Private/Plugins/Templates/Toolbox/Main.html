    Render all toolbox tools in the given order. subhh: custom page grid toggle. Only render it in the toolbox that has the fulltext tool (bottom-toolbar), matching the old installation where the pagegrid button lived inside the fulltext block. Otherwise it would render in every toolbox instance (e.g. also the TOC toolbox with searchInDocumentTool) and produce a duplicate id="pagegrid" — jQuery's $('#pagegrid') would then bind the click handler to only the first occurrence, leaving the visible button unresponsive.
